# ADR-0002：UI 套件使用 Angular Material

- 狀態：已接受
- 日期：2026-10-25

## 背景

後台主要是表格、篩選、分頁和表單（經銷商、管理員、商品、訂單），另外有商品圖片上傳、訂單的日期區間篩選。需要一套 UI 元件，不從零開始寫。

## 決策

- 使用 Angular Material（含 CDK）

## 考慮過的其他方案

- PrimeNG：元件很多，表格內建排序、篩選、後端分頁，也有檔案上傳元件，後台可以少寫一些程式。但由商業公司維護，過去的大版本有過不少破壞性變更（例如主題系統整個改寫），版型範本和舊版本的長期支援要付費

比較的細節見 `docs/plan.md` 第 3 節。

## 影響

- 和 Angular 同時發布，升級最順，文件和範例最多
- 表格要自己組合 `mat-table`、`mat-sort`、`mat-paginator`；檔案上傳沒有現成元件，要用 `<input type="file">` 自己做。這些共用的組合放在 `shared/`，各頁面不要各做一份
- 外觀是 Material Design，客製化比較受限
